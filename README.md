# Yhav Spotify Dashboard

Dashboard de análisis musical que transforma el historial reciente de Spotify en
una experiencia visual e interactiva. Explora canciones y artistas más escuchados
y consulta las reproducciones registradas a lo largo del tiempo.

El proyecto combina una API con FastAPI, una interfaz web propia y una base de
datos para organizar y presentar los datos de escucha. Su objetivo es convertir
la actividad musical cotidiana en información clara y fácil de explorar.
